# Task7.1 Йоркширский терьер — миниатюрная декоративная собака родом из Англии (графство Йоркшир, XIX век), отличающаяся изящным телосложением, длинной прямой шелковистой шерстью (без подшёрстка, похожей на человеческий волос) и характерным тёмно-стальным окрасом с насыщенно-золотым подпалом на голове, груди и лапах. Несмотря на крошечные размеры (рост около 18–20 см, вес до 3,2 кг), это смелый, энергичный и преданный компаньон, который сохраняет терьерский характер — любопытный, бдительный и иногда упрямый.
